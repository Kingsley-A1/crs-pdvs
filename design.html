Design System

The visual language and component conventions for the Cross River State Pensioners Digital Verification System. All colours, type styles, and components are defined here and referenced throughout the prototype.

Colour Palette

Drawn from the Cross River State official brand identity. The deep navy is the primary colour; used in headers, the intro overlay, the admin sidebar, and the footer. The action blue (#2b35b5) is used exclusively for primary call-to-action buttons.

Semantic Tokens

Use semantic tokens in components and pages — never raw hex values. This ensures consistency and makes theming possible.

--color-primary --crs-blue-600 (#1e2275) Sidebar BG, footer, intro overlay, brand uses

--color-error --red-500 (#dc2626) Failed chip, error banner, danger button

Buttons

Primary and secondary buttons carry clear visual hierarchy. Ghost buttons for tertiary actions. Danger/Success for admin review actions only. Always use large size (btn-lg) on pensioner-facing screens.

Used to communicate verification status, case priority, and session type. Always include the dot. Do not use chips for primary navigation.

Form Controls

All pensioner-facing forms use large inputs (form-input--lg) with generous padding. Labels are always visible — never rely on placeholder text as a label. Error states are written in plain English.

As shown on your pension documentation.
We could not find an account with this Pension ID. Please check and try again.

Banners

Used for system-level messages. Always dismissible. Keep banner copy short — one or two sentences maximum. Do not stack multiple banners.

Information
Your next verification is due on 15 June 2026.
Verification Successful
Reference: CRS-VER-2026-0521 · Verified 15 Dec 2025.
Pending Review
Your verification is under manual review. You will be notified of the outcome within 3 working days.
Verification Could Not Be Completed
Please try again or visit an approved support center.

Modal Shell

Modals must have a close button, a title, a body, and a footer with actions. Dismissible by close button, backdrop click, or Escape key. Do not nest modals.

Tables

Used for pensioner records, verification queues, and audit logs. Always wrap in .table-wrapper for horizontal scroll on mobile. Generous padding — rows must not feel cramped.

Status Alerts (Full-Screen)

Used after verification to show the outcome. Always include a primary and secondary action. Keep the message calm and in plain English.

Logo Usage

Use the circular Cross River State emblem (.png) as the primary mark. Use the Think Cross River wordmark (think_cross_river.jpg) only in the footer strip and landing-page context — never as a header logo.

State Emblem — header, intro overlay, footer
